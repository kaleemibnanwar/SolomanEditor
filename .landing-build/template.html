02 / THE AI AGENT

The editor is
an MCP server.

Not a chat widget bolted on the side — the editing session itself is published over the Model Context Protocol. Any MCP host can read the timeline, move clips, grade footage and render exports, live, while you watch.

01
Point any agent at it

Streamable HTTP on loopback — no auth, no relay, no account. Also reachable from the console and over postMessage for extensions and harnesses.

02
A whole editorial pass per call

84 tools across observe, control, import, projects, content, flows, macros and manifests. Compose an entire piece from JSON, or save a recipe and replay it.

03
Templates with slots

Snapshot any project as a template with named slots, then regenerate it with new text and media in a single call. Every call lands as one undo step.
